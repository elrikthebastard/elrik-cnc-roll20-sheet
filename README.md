# Elrik's C&C Roll20 Character Sheet

A community-developed character sheet for playing **Castles & Crusades** on Roll20.

## Project Status

**Active Development / Beta**

This sheet is being rebuilt with an emphasis on making Castles & Crusades faster and easier to run in Roll20 while keeping the underlying game mechanics visible to the player.

The guiding principle is simple:

> **More Adventure. Less Bookkeeping.**

The sheet automates arithmetic and repetitive bookkeeping where practical. Rules decisions, situational modifiers, character choices, and Castle Keeper judgement remain with the players and CK.

## Current Goals

- Complete support for the core C&C character classes
- SIEGE Engine attribute checks
- Automated but transparent combat calculations
- Weapons, armour and inventory management
- Spellbook, memorization and spell-resource management
- Class and racial abilities
- Single Class characters
- Dual Class characters
- Multi-Class characters
- Enhanced / Class-and-a-Half characters
- Class Plus characters
- Reclassed characters
- Built-in help and documentation
