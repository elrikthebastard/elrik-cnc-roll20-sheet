Help & Documentation

Quick answers first. Open only the section you need.

Enter the character's core information first, then use the dedicated pages to manage weapons, equipment, spells and abilities. Tools contains character setup, SIEGE targets, roll preferences and repair controls.

Design rule: secondary pages manage things; Core surfaces the things you use most often in play.

Single Class is the current fully active class structure.

Dual Class is for an established character who later begins another class. The original class remains the character's existing Class and Level. The new class can move through Training, Level 0 and Level 1+ states. Dual Class now exposes derived rules context while protecting existing HP, XP and primary BtH values during this test phase.

Multi-Class is a separate system in which the classes advance together. This sheet presumes you have discussed and approved the class combination with your Castle Keeper; it will not police the published combination table.

Enhanced / Class-and-a-Half, Class Plus and Reclass remain reserved for later implementation.

Primary, Secondary and optional Tertiary targets are configured in Tools. Automated checks use the configured target and the character data available to the sheet; situational judgement remains with the player and Castle Keeper.

The sheet is intended to make its arithmetic inspectable. Attack cards separate the natural d20 from the modifier and final total. Derived class, AC and spell information is rebuilt from authoritative character data rather than replacing entered source data.

If generated class, race, equipment or Core information looks stale after a change, use Tools → Rebuild Character. Rebuild is designed to regenerate derived information while preserving entered character data.
